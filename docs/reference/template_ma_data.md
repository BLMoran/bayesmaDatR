# Create a blank workbook template

Create a blank workbook template

## Usage

``` r
template_ma_data(rob_tool = "rob2")
```

## Arguments

- rob_tool:

  Risk-of-bias tool(s) whose domain columns are added to the
  `risk_of_bias` sheet. See
  [`rob_tools()`](https://blmoran.github.io/bayesmaDatR/reference/rob_tools.md).

## Value

An empty `ma_data` object with the recommended columns.
