# Built-in risk-of-bias tools

The tools supported by robbR: RoB 2 (`"rob2"`), ROBINS-I V2
(`"robins_i"`), ROBINS-E (`"robins_e"`), QUADAS-2 (`"quadas2"`), CLARITY
(`"clarity"`), RoB NMA (`"rob_nma"`), PROBAST (`"probast"`) and
PROBAST+AI (`"probast_ai"`).

## Usage

``` r
rob_tools()
```

## Value

Character vector of supported tool identifiers.
