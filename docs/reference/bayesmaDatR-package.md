# bayesmaDatR: Manage and Prepare Data for Bayesian Meta-Analysis

Import, manage, validate, and prepare systematic review data for
Bayesian meta-analysis. Provides an interactive Shiny workbook manager,
outcome-specific effect-size calculations, arm-level data preparation,
risk-of-bias fields, and INSPECT-SR data management.
