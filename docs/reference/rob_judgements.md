# Accepted judgements for a risk-of-bias tool

Judgements are matched case-insensitively against the standard levels
and their common synonyms (e.g. `"low risk"` for `"Low"`), as in robbR.

## Usage

``` r
rob_judgements(rob_tool = "rob2")
```

## Arguments

- rob_tool:

  Tool identifier from
  [`rob_tools()`](https://blmoran.github.io/bayesmaDatR/reference/rob_tools.md).

## Value

Character vector of standard judgement levels.
